# Sources and licensing

These rule data files are derived from [MetaCubeX/meta-rules-dat](https://github.com/MetaCubeX/meta-rules-dat), not independently maintained domain lists. Rivo only selects preset categories and retains `DOMAIN-KEYWORD` and `DOMAIN-REGEX` entries from `geo/geosite/classical/<tag>.list`. The matching domain and IP MRS files remain hosted and maintained by MetaCubeX. No advertising category is selected.

Each generation resolves the upstream `meta` branch to one immutable commit before downloading any rules. `manifest.json` records that SHA, generation time, source URLs, SHA-256 digests, source rule counts, and retained rule counts. A category with no retained rules still has a comment-only file, allowing future upstream additions without changing configuration.
